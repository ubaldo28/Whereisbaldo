Put post photos in this folder.

Then add them to the top of a post file:

    heroImage: "../../assets/posts/your-photo.jpg"
    heroAlt: "Short description of what is in the photo"

Astro resizes the photo, converts it to modern formats and serves each visitor
the size their screen needs. Drop the original in here at full resolution —
do not shrink it first.

Photos placed in /public are NOT processed. Only this folder is.
